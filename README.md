## ASCII WOLFENSTEIN 3D RENDERER

A Renderer, built in C++, to imitate the [Wolfenstein 3D](https://en.wikipedia.org/wiki/Wolfenstein_3D) renderer.

Resources used:

> [OneLoneCoder.com - 3D FPS Shooter in CMD-Line](https://www.youtube.com/watch?v=xW8skO7MFYw)

> Wikipedia

> ChatGPT (Assisted in the math formulas involved, helped explain concepts indepth. **NO CODE GENERATED BY IT**)

> Graphics Programming notes from College

> Math notes from College

## Running the Program

1. Clone the Repo.
2. Navigate to where you downloaded the Repo.
3. Open it, and double click the ASCII-FP folder.
4. Double click ASCII-FP.cpp and open with your IDE of choice.
5. Run the program.

## Controls
Movement: W/A/S/D

Rotation: E (Clockwise), Q (Counter-clockwise)
